# 민원서비스 찾기

민원인이 원하는 민원 서비스를 빠르게 찾을 수 있도록 `민원서비스_목록.json`(22건)을 검색·필터하는 정적 웹페이지입니다.

## 기능
- 22건 전체 표시 (원본 자료를 index.html에 그대로 내장)
- 서비스명 키워드 검색 (띄어쓰기 무시, 일치 부분 강조)
- 민원분야 필터 — 검색어와 동시 적용
- 온라인처리(가능/불가) 필터, 처리기한·수수료 정렬, 조건 초기화
- 현재 표시 건수 표시 (전체 22건 중 N건)
- 반응형 (모바일 1열 · 태블릿 2열 · PC 3열), 다크 모드, 키보드 접근성

## 구성
- `index.html` — HTML/CSS/JS 단일 파일
- `민원서비스_목록.json` — 원본 자료
